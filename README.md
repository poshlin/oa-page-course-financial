## 章節順序（2026-08-13 保旭拍板 A 案，動任何章節前先讀）

頁面經歷過三次定位變化——**先以平台角度設計 → 改成課程角度 → 再補進教學部課程概要**——順序一度殘留「平台優先」的痕跡。已依家長決策順序重排：

| # | id | 章節 | 家長此刻在問 |
|---|---|---|---|
| — | hero／tldr | 標題＋結論先行 | 這是什麼？值得看嗎？ |
| 01 | `why` | 為什麼需要兒童理財教育 | 我孩子需要嗎？ |
| 02 | `syllabus` | **學什麼**（45 堂完整課表） | 他到底會學到什麼？ |
| 03 | `class` | 一堂課怎麼上 | 誰在教？跟得上嗎？ |
| 04 | `course` | 孩子怎麼學（關卡／角色／課堂實境） | 學習過程長什麼樣？ |
| 05 | `practice` | **課後的練習場**（平台機制＋經濟模組） | 課後怎麼練？ |
| 06 | `report` | 家長看得到（學習週報） | 我看得到成效嗎？ |
| 07 | `fit` | 適合誰 | 適合我家嗎？ |
| 08 | `faq` | 常見問題 | 我還有疑慮 |
| — | `cta` | 底部 CTA | 行動 |

三條不可回退的原則：

1. **最硬的證據（45 堂課表）必須排在平台內容之前**。它是全頁說服力最強的東西，被平台機制擋在後面等於自廢武功。
2. **平台只能有一段，且位置在課程之後**。舊版拆成「03 平台怎麼運作」與「06 課堂之外」兩段、中間夾著課程內容，是平台優先時代的殘留；已合併為 05。合併同時把平台從「產品主角」降格為「課後練習場」，這才符合「雙師課程＋平台」的定位（見 CLAUDE.md 第 6 條）。
3. **02 講知識內容、04 講學習過程，兩者分工不得混淆**。04 舊名「課程內容」會讓人以為內容已經講完，已改名「孩子怎麼學」，並用「剛才那 45 堂，孩子實際上是這樣走過去的」承接 02。

背景節奏採交錯：`why`（奶油）→ `syllabus`（cream-2）→ `class`／`course`（奶油）→ `practice`（cream-2）→ `report` → `fit`（奶油）→ `faq`（cream-2）→ `cta`（深）。浮動索引列 7 項與上表 01–08 對應（`fit` 不進索引列）。
